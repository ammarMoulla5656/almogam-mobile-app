# تطبيق المعاجم

تطبيق عربي يعمل بثلاثة معاجم منفصلة: المعجم الفقهي، والمعجم الأصولي، والمعجم اللغوي. يضم المعجم اللغوي كتاب العين بأجزائه الأربعة ومادة `MeaningLang`، وتُعرض التعريفات بعد تنظيف وسوم التنسيق والعلامات المخفية.

## تشغيل التطبيق وبناؤه

```bash
npm ci
npm run dev
```

لبناء نسخة الويب:

```bash
npm run build
```

لمزامنة ملفات الويب مع مشروع Android:

```bash
npm run android:sync
```

ويُبنى APK من GitHub Actions عبر سير العمل الموجود في `.github/workflows/build-android-apk.yml`.

## ملفات البيانات

- الملفات النهائية التي يستوردها التطبيق: `database/processed/unified_fiqhi.json` و`unified_usuli.json` و`unified_lughawi.json`.
- نسخ المصادر الأصلية: `database/original_sources/`.
- أجزاء كتاب العين الأربعة، مع حذف المصطلحات المكررة عند الدمج.
- ملفات تجهيز الفهرسة الدلالية: `database/vector_upload/fiqhi.txt` و`usuli.txt` و`lughawi.txt`.

بعد استبدال مصادر المعاجم، أعد إنشاء البيانات الموحدة وملفات البحث الدلالي هكذا:

```bash
node scripts/merge_dictionary_sources.mjs
```

تُنظف عملية الدمج وسوم HTML والعلامات الخفية، وتجمع صفوف التعريفات المتتابعة في `MeaningLang.json`، وتدمج المدخل المتكرر في بطاقة واحدة مع الحفاظ على صيغ البحث البديلة. ربط «انظر/راجع» يقتصر على المصطلح الموجود في المعجم نفسه.

لتحديث ملفات نصوص الفهرسة بعد أي تعديل يدوي على البيانات الموحدة:

```bash
node scripts/prepare_vector_upload.mjs
```

تحديث ملفات `vector_upload` محلياً لا يرفعها تلقائياً إلى مخازن OpenAI؛ يجب تحديث مخزن كل معجم بملفه الموافق. مفتاح OpenAI يبقى محفوظاً كسِر في Cloudflare Worker ولا يوضع في ملفات المشروع.
