# قاعدة بيانات التطبيق

## البيانات التي يقرأها التطبيق

تعريفات المعاجم الموحدة موجودة في `processed/`:

- `unified_fiqhi.json` — المعجم الفقهي.
- `unified_usuli.json` — المعجم الأصولي.
- `unified_lughawi.json` — المعجم اللغوي، ويشمل كتاب العين وملفات اللغة.

يستورد التطبيق هذه الملفات مباشرة. وتوجد نسخة مجمعة متوافقة في `app_active_data/dictionaries.json`.

## المصادر والملفات الوسيطة

- `original_sources/` يحفظ ملفات Meaning وأجزاء كتاب العين الأصلية.
- `processed/kitab_al_ayn.json` نسخة مدمجة بلا تكرار لأجزاء كتاب العين.
- `vector_upload/` يحوي ملفاً مستقلاً لكل معجم لاستخدامه في الفهرسة الدلالية.

لتحديث الملفات الموحدة بعد إضافة المصادر، شغّل من مجلد المشروع:

```bash
node scripts/merge_dictionary_sources.mjs
```

التحديث المحلي لملفات الفهرسة لا يرفعها إلى مزود البحث السحابي؛ يجب استبدال ملفات مخازن المعاجم الثلاثة كلٌ بملفه.
