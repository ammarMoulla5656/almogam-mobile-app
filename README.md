# تطبيق المعجم (Al-Mojam Mobile App) 📘

تطبيق موبايل احترافي وسريع جداً للأندرويد (مع جاهزية كاملة للآيفون iOS عبر Capacitor) يضم **المعجم الفقهي (كتاب الاصطلاحات الفقهية في الرسائل العملية - ١٤٠٩ مصطلحات كاملة)** بالإضافة إلى أقسام معاجم أخرى قابلة للزيادة والتوسيع.

## ✨ المميزات المنفذة بالكامل
1. **خانة المعجم الفقهي + تعدد المعاجم**: يحتوي افتراضياً على كتاب *"الاصطلاحات الفقهية في الرسائل العملية"* للشيخ ياسين عيسى العاملي مفرغاً بالكامل (١٤٠٩ مصطلحات مع مصادرها وأرقام صفحاتها)، بالإضافة إلى إمكانية إضافة معاجم جديدة من داخل التطبيق أو عبر ملفات JSON.
2. **نظام البوكسات التفاعلية (Accordion Boxes)**: كل مصطلح أو عبارة ضمن بوكس أنيق؛ عند الضغط عليه يفتح الجواب الكامل مع المصادر ورقم الصفحة، وأزرار **نسخ الجواب** و**مشاركة** و**حفظ في المفضلة**.
3. **ثيم أبيض وثيم أسود (Light & Dark Mode)**: تبديل فوري بين الوضع النهاري (الأبيض) والوضع الليلي (الأسود) المريح للعين مع التحكم بحجم الخط.
4. **فهرسة مطابقة لفهرس الكتاب**: فهرس كامل للأبواب الأبجدية الـ ٢٨ (من حرف الهمزة ص ٩ إلى حرف الياء ص ٢٣٣) مع قائمة المصادر الـ ٤٨ المعتمدة في الكتاب.
5. **محرك بحث ذكي وشامل للمحتوى**:
   - لا يشترط كتابة الكلمة بالضبط (يتجاهل الهمزات، التشكيل، التاء المربوطة/الهاء، الألف المقصورة/الياء، والـ تعريف واللواحق).
   - يبحث داخل **المحتوى والشرح** ويدعم المترادفات الدلالية والتسامح مع الأخطاء الإملائية (`Fuzzy Search`).
6. **قابلية الزيادة عبر ملف JSON أو الإضافة المباشرة**:
   - الملف المستقل للبيانات موجود في: [`src/data/dictionaries.json`](file:///mnt/d/almogam/src/data/dictionaries.json).
   - يمكنك أيضاً استيراد أو تصدير ملفات `JSON` أو إضافة مصطلحات ومعاجم جديدة مباشرة من تبويب **"إضافة / ملفات"** داخل التطبيق.

## 🚀 طريقة التشغيل والبناء للأندرويد والآيفون

### 1. التشغيل المباشر للمعاينة والتجربة
```bash
npm install
npm run dev
```

### 2. بناء التوزيعة النهائية للإنتاج (Web / PWA / Mobile Bundle)
```bash
npm run build
```

### 3. توليد مشروع الأندرويد (Android APK / Android Studio) والآيفون (iOS Xcode)
التطبيق مهيأ بالكامل عبر [`capacitor.config.json`](file:///mnt/d/almogam/capacitor.config.json):
```bash
# لإضافة وبناء نسخة الأندرويد
npx cap add android
npx cap sync android
npx cap open android

# مستقبلاً لإضافة وبناء نسخة الآيفون (على نظام macOS)
npx cap add ios
npx cap sync ios
npx cap open ios
```
